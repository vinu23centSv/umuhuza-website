# UMUHUZA Website Starter

A separate Next.js website starter for the UMUHUZA dating platform. It does not modify or connect to the existing app.

## Requirements
- Node.js 20.9 or newer
- npm

## Run locally
1. Extract the project folder.
2. Open a terminal in `umuhuza-website`.
3. Run `npm install`.
4. Run `npm run dev`.
5. Open http://localhost:3000.

## Before publishing
- In `app/page.tsx`, replace `PLAY_STORE_URL` with the official Google Play listing URL.
- Add `DIRECT_DOWNLOAD_URL` only if you have a trusted, official direct APK download.
- Replace sample couple images and example testimonials with real photos/stories you have permission to publish.
- Review privacy, contact, and terms links before launch.

## Deploy
Push this folder to a new GitHub repository and import that repository into Vercel. Do not import or overwrite the repository used by the existing app.
